# LeetCode

My ongoing **C++ data structures and algorithms practice**.

The repository is intentionally organized around problem-solving patterns rather than copying large solution sets.

## Current coverage

- Hash tables
- Strings
- Sorting
- Arrays
- Two-pointer / scanning patterns as they are added

## How I use this repo

For each problem, the aim is to keep:

1. the problem link or identifier,
2. a clean C++ solution,
3. the core idea / pattern,
4. complexity analysis.

The repository will grow as I work through more problems.
